## 本地验收

在没有复用 node_modules 的临时目录中，三个仓库均通过：

```bash
npm ci --offline --no-audit --no-fund
npm run build
npm test
```

- Core：24 个测试文件，189 项测试通过。oxlint 无警告。
- 官方插件：31 项测试通过。
- 私有插件：37 项测试通过，包括迁出的 Maker 协议检查。
- 文件服务：9 项存储和真实 HTTP 协议检查通过。
- 视频：1 项真实本机 WebSocket 与合成 RGB 协议检查通过，包含 PNG 像素无损检查。

Firefox 生产预览检查覆盖空目录，以及十四个插件逐一单独安装加载。
实际挂载了面板、图像设置分页和终端抽屉，没有点击运动或 SSH 连接操作。
卸载再安装检查确认插件状态、面板记录和 Dockview 几何布局保留。
浏览器检查阻止机器人连接和 API 请求，ROS 检查使用独立 domain 与本机合成图像。

命令和配置详见 [08-plugin-packages.md](08-plugin-packages.md) 与 [09-companion-services.md](09-companion-services.md)。
